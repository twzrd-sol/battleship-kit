# Change sizing

There is no standing line-count cap per turn, batch, commit, PR, or task.
Size changes to complete the authorized task coherently, keeping the tests and
documentation with the implementation. Review diffs and run the relevant checks
at meaningful checkpoints; never stop or ask for approval solely because of
line count.

What does still stop an agent: task scope, explicit review checkpoints,
ownership, deployment, spending, outreach, and any action that signs with a key.
