# Generic leak patterns. Safe to publish: shapes only, no names.
# One pattern per line, grep -E, case-insensitive. A line starting with # is a comment,
# so a pattern that must START with # is written [#]...
# YOUR identifiers (private repo names, hostnames, buckets, people, vendors under
# embargo) belong in a LOCAL list that never enters this repository. See scan.sh.

# base58 strings of 32-byte address length (Solana-style wallets)
\b[1-9A-HJ-NP-Za-km-z]{32,44}\b
# base58 strings of 64-byte secret-key length (a Solana keypair is 86 to 88 characters)
\b[1-9A-HJ-NP-Za-km-z]{80,90}\b
# 64 hexadecimal characters: a 32-byte key, or the hash of a secret
\b[0-9a-f]{64}\b
# a keypair written as a JSON array of 64 byte values
(\b[0-9]{1,3}, ?){63}[0-9]{1,3}\b
